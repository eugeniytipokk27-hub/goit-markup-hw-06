# goit-markup-hw-06

Responsive WebStudio homework based on HW-05.

## Breakpoints

- Mobile: from 320px
- Tablet: from 768px
- Desktop: from 1158px

## Implemented

- Mobile First styles with `min-width` media queries
- Mobile menu with `id="mobile-menu"` and `.is-open` state
- Responsive `1x` / `2x` raster content images via `src` + `srcset`
- Responsive Hero backgrounds via `image-set()`
- Separate mobile, tablet, and desktop Hero graphics
- Fixed `264px` Our Team cards on every breakpoint
- Portfolio overlay on all viewport widths
- Responsive HW-05 modal
- `modern-normalize` minified stylesheet
- Prettier configuration and npm format scripts

## Format

```bash
npm install
npm run format
```

## GitHub

Create a repository named `goit-markup-hw-06`, copy these files into it, commit,
push, and enable GitHub Pages from the repository settings.
